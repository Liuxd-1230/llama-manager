# Atelier 更新记录 · 2026-10-28

本次将此前的 Atelier 创作工作台整合、品牌与交互精修、运行可靠性修复统一提交。保留现有 React / TypeScript 与 Python / FastAPI 技术栈。

## 交付内容

- 统一工作台、创作、模型、下载、素材、对话和设置入口，共用品牌资产、基础控件、主题变量和面板动效。
- 将模型服务、创作编译、下载、ComfyUI、MCP 与持久化任务接入统一后端；API 使用 `/api/v1`，前端类型由 OpenAPI 生成。
- 下载展示实际字节、速度和剩余时间，处理暂停、断点恢复、取消、连接清理与任务重启状态；目录选择保留原生窗口和网页备用方式。
- 普通对话与创作 Agent 保留真实流式输出，修复订阅尾部丢失；输入法、滚动、思考折叠和连接恢复使用共享规则。
- 创作 Agent 对仿写执行日志但没有真实工具记录的回复增加核验与一次重试；仍未执行则报告失败。旧记录只增加读取时的提示，不补造提案或改写原始消息。
- 创作输入区由外层统一绘制圆角焦点环，移除内部直角焦点框；精简重复说明，保留操作条件、失败原因和参数后果。
- 保留工作流独立参数、版本冲突与固定内容保护。外部 ComfyUI 继续由用户管理，Atelier 不安装、启停或全局中断它。

## 使用说明

- 聊天模板当前通过本地文件路径配置，不支持直接在界面粘贴、编辑或一键复制模板正文；详见 README。
- Agent 修改构图文档并生成提案；已生成图片需要重新出图才体现修改。
- 数据默认存放于 `%LOCALAPPDATA%/Atelier`。迁移保留旧来源，凭据沿用环境变量及 Windows DPAPI；用户数据库、凭据、截图包和本地工具配置不随本次源码发布。
